⚠ Looks like a CORS block. Confirmed live: eurex.com responds 200 OK but never adds Access-Control-Allow-Origin for any origin — the browser discards the response regardless of whether this file is opened locally or from a real domain. Also important: besides CORS, this endpoint has a second, independent check — without a browser Referer header pointing at eurex.com's own statistics page, it returns an empty body. Spoofing Referer from a browser fetch() is impossible by design (one of the few headers JS can't override) — so the only way around it is a proxy server that sets both headers itself:
export default { async fetch(req) { const url = new URL(req.url); const headers = { "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/124.0 Safari/537.36" }; let target; if (url.pathname.startsWith("/yproxy")) { // live DAX index quote (Yahoo Finance) — used for the live price layer target = "https://query1.finance.yahoo.com" + url.pathname.replace("/yproxy","") + url.search; } else { target = "https://www.eurex.com" + url.pathname.replace("/proxy","") + url.search; headers["Referer"] = "https://www.eurex.com/ex-en/data/statistics/market-statistics-online"; } const r = await fetch(target, { headers }); return new Response(await r.text(), { status: r.status, headers: { "Content-Type": "application/json", "Access-Control-Allow-Origin": "*" } }); } }
Deploys free in 5 minutes on cloudflare.com → Workers & Pages → Create Worker → paste the code → Deploy. Take the resulting address (e.g. https://your-worker.workers.dev/proxy) and paste it into the "Proxy URL" field below, then click "Save" — auto-refresh will then genuinely work. This same worker also carries the live DAX index quote (via /yproxy) that the underlying price uses — if you already deployed the old version, just replace its code with this one and redeploy; the "Proxy URL" field doesn't need to change.
✓ About auto-refresh and dates. The tabs above are the real upcoming ODAX expiry Fridays, computed right in the browser (weekly + monthly — third Friday of the month), not a made-up list. For each date the page requests eurex.com/api/v1/overallstatistics/70044?productdate=<expiry date>&busdate=<last trading day>&contracttype=W|M — on load and then every 15 minutes. Confirmed live (not a guess): eurex.com responds to these requests normally (200 OK, real data comes back), but never adds an Access-Control-Allow-Origin header for any origin — so the browser discards the response no matter whether this file is opened locally or from a real domain. The only working workaround is the proxy in the note above.
✓ About the DAX price. Three layers, per priority: (1) a real FDAX future settlement with the exact same expiry date, via the free Eurex Reference Data API — usually only matches quarterly dates, since the future itself is quarterly-only, unlike the options; (2) put-call parity: F ≈ strike + CallSettlement − PutSettlement, median across all strikes priced on both sides — works for any expiry, accurate to within a point; (3) highest-OI strike, last resort. On top of whichever of those resolves, a live DAX index quote (Yahoo, ^GDAXI) is added as today's live move so the number tracks the market during the day instead of sitting frozen at yesterday's settlement — refreshed hourly, plus on every manual "Refresh" click. The small tag next to the price shows LIVE when that layer is active, or the plain settlement method name (FUTURE/PARITY/EST) when the live quote isn't reachable — in which case the number is EOD-only and won't move until the next session, by design, not a bug. The live quote is fetched the same way as the OI data: direct browser fetch first, falling back to the proxy above (via its /yproxy route) if that's blocked.
